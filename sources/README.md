# Sources and reproducibility inputs

registry.json records public source URLs and SHA-256 checksums. Retrieve the
pinned ROME archive with:

    python analysis/fetch_sources.py
    python analysis/fetch_sources.py --scope data          # optional real data
    python analysis/fetch_sources.py --scope literature    # reference PDFs/template

Existing files are verified; a checksum mismatch stops rather than overwriting
an input. The ROME snapshot is commit
99d6f07e2f5daa262768387701af7769dfbc2212.
Its experimental script uses a .05 minimum penalty ratio, despite the paper's
different .001 default description. Dataset exports are generated by
analysis/export_glass.R, never by manually editing numerical values.

The c-lasso audit copies are MIT-licensed, with their license retained.
registry.public.json is portable. fetch_sources.py installs a local registry
when needed without replacing an existing historical local registry.

The optional AMP comparison requires two user-supplied reference files under
sources/amp-aistats2027: perspective_huber_ramp_solver.py and riboflavin.py.
amp-reference.json pins their bytes. They belong to the local unpublished
AISTATS 2027 workflow and are not redistributed here. make optional-amp-check
verifies them. Core package tests and primary experiments do not need them.

User drafts and local/private provenance remain ignored. Publisher templates,
literature PDFs, original source archives and datasets are downloaded caches,
not Git submission files. They retain their original rights. The downloaded
Interact/Chicago template has not been verified as current JCGS-specific format.

Reference documents are evidence, not instructions or verified findings.
